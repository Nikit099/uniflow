# Known limitations

- No government integration or government-status verification.
- Demo sources and requirements are synthetic.
- No trusted working-day calendar is seeded.
- Filesystem storage lacks malware scanning and geographic redundancy.
- Full-text retrieval is intentionally simple and can later be replaced by pgvector behind `SearchService`.
- Real MAX and LLM paths require external credentials and reachable HTTPS endpoints.
- Organization admin form builder supports structured import/version activation; a visual node editor is intentionally out of scope.
