# Data provenance

Origins: `OFFICIAL_SOURCE`, `UNIVERSITY_CONFIG`, `USER_INPUT`, `STAFF_INPUT`, `SYSTEM_CALCULATION`, `LLM_GENERATED`, `SYNTHETIC_DEMO`, `EXTERNAL_INTEGRATION`.

Truth priority: official source → verified university configuration → staff input → system calculation → AI explanation. AI is never a source of truth. Requirements without verified evidence cannot silently become official requirements. Demo seed, fixtures and metrics are visibly marked synthetic.
