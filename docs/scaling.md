# Scaling

Stable core: user, case, procedure engine, requirements, review, source library, notification outbox, grounded AI and audit.

Variable layer: organization, procedure versions, rules, deadlines, sources, languages, memberships and external adapters. The path is Demo University → one verified pilot university → second tenant → additional procedure → multi-university platform.

Candidate procedures are visa extension, repeat entry, address change, lost-document recovery, migration-registration extension and graduation. They should be added as configuration after source and owner validation, not hardcoded UI branches.
