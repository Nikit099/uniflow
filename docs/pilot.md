# Pilot plan

Start with one university, 20–50 international students and 2–5 staff members. Compare As-Is and To-Be for first-pass completeness, review cycles, staff handling time, student completion time, repeated questions and case completion rate.

All target improvements are hypotheses until measured. Before launch agree the personal-data basis, process owner, source verification owner, retention/deletion rules, document storage boundary, escalation path and responsibility wording.
